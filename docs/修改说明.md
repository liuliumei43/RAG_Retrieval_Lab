# 来源和本次修改

本仓库是基于开源代码的学习与改进版本。原作者为 Santanu Mohanta，上游仓库为 https://github.com/santanu2908/chat-with-pdf-rag ，引入提交为 `6fb4e9cfd0c190a950aadb49f7bb089fafe86e5e`。保留 MIT 许可证、作者版权与已有 Git 历史。

## 沿用的实现

PDF 分块、MiniLM embedding、FAISS + BM25 + RRF、cross-encoder 重排、FastAPI、流式回答、会话记忆、虚构示例 PDF 和 19 项真实模型问答用例均来自上游。

## 2026-11-15 的小幅修改（AI 辅助）

- 用内存流读取 PDF，移除固定临时文件。
- 让 BM25 仅对正分命中参与 RRF。
- 延迟导入 embedding 和重排模型，基础测试无需安装或下载模型。
- 添加基础回归测试，将真实模型测试标为 live 并默认排除。
- 去掉完整会话调试打印；修正重排注释和流式字符串兼容性。
- 增加中文 README、学习指南和最小测试依赖。

## 验证范围

以 `python -m pytest -q` 的本地输出为准。基础测试使用构造向量和模型替身，不代表真实模型回答质量；本次不调用付费模型，不重复引用上游的成功率作为本版成绩。

本地验证：Python 3.12，16 项基础测试通过，19 项真实模型测试默认排除；出现一条依赖弃用提示。未下载 embedding/重排模型，未调用付费模型。
